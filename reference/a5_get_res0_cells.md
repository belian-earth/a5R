# Get all resolution-0 root cells

Returns the 12 root cells corresponding to the 12 faces of the
dodecahedron.

## Usage

``` r
a5_get_res0_cells()
```

## Value

An [a5_cell](https://belian-earth.github.io/a5R/reference/a5_cell.md)
vector of length 12.

## Examples

``` r
a5_get_res0_cells()
#> <a5_cell[12]>
#>  [1] 0200000000000000 0600000000000000 0a00000000000000 0e00000000000000
#>  [5] 1200000000000000 1600000000000000 1a00000000000000 1e00000000000000
#>  [9] 2200000000000000 2600000000000000 2a00000000000000 2e00000000000000
```
